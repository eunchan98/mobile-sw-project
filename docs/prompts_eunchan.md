  - 탄·단·지 그램 표시: "소수점 한 자리 (추천)" (계산은 소수점까지 그대로)

  - `NutritionCalculator`: 음식 하나(100g당 값 × 섭취량/100), 음식 항목, 한 끼, 여러 끼 합계

  - `IntakeAmount`: 섭취량 입력 검사 (1~2000g, 소수점 한 자리)
  - 단위 테스트 15개 추가 (계산 8, 표시 4, 입력 검사 3), 전체 21개 통과
  - 테스트 중 버그 발견·수정: 14.7 × 1.5 = 22.0499…로 계산되어 22.1g이 아닌 22g으로 표시되던 부동소수점 반올림 오류
  - docs/foundation.md에 팀원용 사용법 추가

- 인터뷰: 같은 메뉴가 여러 건일 때 어떤 값을 쓸지
  - 답변: "성인 기준으로 가장 보편적인 걸로 가야되지않을까?"
  - 적용: 업체(프랜차이즈) 제품·간편조리세트·학교급식을 빼고, 성인 대상 출처(산업체급식·가정식·외식 분석/산출)의 중간값 사용. 성인 출처에 없는 김치볶음밥·순두부찌개만 다른 출처 값 사용
