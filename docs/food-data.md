# 음식 데이터 (foods.csv) 만들기

과제 요구사항: 식품의약품안전처 등 공공 데이터베이스의 자료로 약 100개 음식의 열량·영양소를 계산하고, 출처를 앱에 표시한다.

## 1. 원본 데이터 받기

식품의약품안전처 **식품영양성분 데이터베이스** (https://various.foodsafetykorea.go.kr/nutrient/)
- "음식" 분류의 통합 자료를 엑셀/CSV로 내려받거나, 공공데이터포털(data.go.kr)의 "식품의약품안전처_통합식품영양성분정보" 파일을 사용한다.
- 내려받은 파일 이름과 기준일(데이터 버전)을 README의 "영양 데이터 출처"에 적는다.

## 2. 100종 고르기

학생 식당에서 자주 나오는 메뉴 위주로 고른다: 밥류, 국·찌개류, 볶음·구이·조림류, 튀김류, 면류, 김치·나물 반찬, 빵·음료·간식.

## 3. foods.csv 형식

```
id,name,category,kcal,carbs,protein,fat
1,쌀밥,밥류,143,31.7,2.5,0.3
```

- 영양소는 **100g 기준**: 에너지(kcal), 탄수화물(g), 단백질(g), 지방(g)
- 원본이 1회 제공량 기준이면 100g 기준으로 환산한다: `값 × 100 / 기준량(g)`
- 이름에 쉼표(,)를 쓰지 않는다. id는 1부터 겹치지 않게 매긴다.
- 맨 위 `#` 주석 줄은 무시되므로 출처 메모를 남겨도 된다.

## 4. 반영 확인

- `./gradlew :app:testDebugUnitTest` 로 파서 테스트 통과 확인
- 앱은 DB가 비어 있을 때만 foods.csv를 읽는다. 이미 설치된 앱은 **앱 데이터 삭제(또는 재설치)** 후 실행해야 새 데이터가 들어간다.
