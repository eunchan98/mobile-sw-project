# 음식 데이터 (foods.csv) 만들기

과제 요구사항: 식품의약품안전처 등 공공 데이터베이스의 자료로 약 100개 음식의 열량·영양소를 계산하고, 출처를 앱에 표시한다.

## 1. 원본 데이터

- 공공데이터포털(data.go.kr) 「전국통합식품영양성분정보(음식)표준데이터」 CSV (제공: 식품의약품안전처, 데이터 기준일자 2026-09-29, 19,738건)
- 제목에 **(음식)** 이 붙은 자료를 받는다. 붙지 않은 「전국통합식품영양성분정보표준데이터」는 업체 가공식품 자료라 학생식당 메뉴로 쓸 수 없다.
- 원본 파일은 크기 때문에 레포에 올리지 않는다. 인코딩은 CP949.

## 2. 변환

```bash
python tools/build_foods.py <내려받은 CSV 경로>
```

`app/src/main/assets/foods.csv`를 새로 만든다. 고를 메뉴는 스크립트의 `MENU` 목록(분류, 원본 식품명, 앱 표시 이름)에서 바꾼다.

**값 고르는 규칙** (성인 기준으로 가장 보편적인 값)
1. 식품명이 정확히 같은 행만 쓴다. 업체(프랜차이즈) 제품과 간편조리세트는 뺀다.
2. 성인 대상 출처(산업체급식, 가정식 분석, 외식 분석·산출)의 값을 쓰고, 여러 건이면 **중간값**을 쓴다.
3. 성인 대상 출처에 없으면 학교급식 등 나머지 출처의 중간값을 쓴다. (현재 김치볶음밥, 순두부찌개)

원본 값이 이미 100g(음료는 100ml) 기준이라 환산하지 않는다. 음료는 1ml ≈ 1g으로 보고 섭취량(g)에 그대로 입력한다.

## 3. foods.csv 형식

```
id,name,category,kcal,carbs,protein,fat
1,쌀밥,밥류,166,37.3,3.4,0.3
```

- 맨 위 `#` 주석 줄(출처, 기준일자, 규칙)은 앱이 무시한다.
- 직접 고치지 말고 스크립트를 수정해 다시 만든다.

## 4. 반영 확인

- `./gradlew :app:testDebugUnitTest` 로 파서 테스트 통과 확인
- 앱은 DB가 비어 있을 때만 foods.csv를 읽는다. 이미 설치된 앱은 **앱 데이터 삭제(또는 재설치)** 후 실행해야 새 데이터가 들어간다.
